# LUMA Motion Ads — Scripts (Phase 1)

Source of truth for on-screen copy, shot timing, and CTAs. Brand tokens and
global rules: see docs/superpowers/specs/2026-06-25-luma-motion-ads-design.md §Global Constraints.

On-screen languages are deliberately mixed (Arabic / English / Franco) — that IS the demo.

## Archetype 1 — ezayyy? (REACH / follower track) · ~12s
Franco flex. Goal: stop the scroll, earn the follow.

| t | on-screen | copy |
|---|---|---|
| 0–3s | 3 DM bubbles pop in, stacked: `عندكوا المقاس ده؟` · `how much is shipping?` · `3ayez ashoof el catalog` | Hook: "Your customers don't all type the same way." |
| 3–9s | LUMA reply bubbles type out under each — perfect Arabic, English, Franco | "LUMA gets all of them." |
| 9–12s | Bubbles collapse into LUMA wordmark + handle | CTA (soft): "Follow → lumabot.ai" |
